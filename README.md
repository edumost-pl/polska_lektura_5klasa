# Polska Lektura — klasa 5

Движок для чтения школьных lektur в оригинале. Текст книги живёт в JSON. JavaScript один на все книги: новую lekturę можно добавить, не меняя код.

Сейчас в списке одна книга — *Chłopcy z Placu Broni*. В `chapter-01.json` лежит короткий **пробный** текст, не оригинал книги. Его нужно заменить текстом из вашего издания.

Проект не запоминает, что ребёнок уже прочитал. Нет процентов, статусов глав и записи в браузере. Результат quiz виден только до обновления страницы.

## Как открыть

Из папки `polska_lektura_5klasa`:

```bash
python3 -m http.server 8765
```

Потом откройте [http://localhost:8765/](http://localhost:8765/).

Файл `index.html` нельзя открывать двойным щелчком: браузер блокирует загрузку JSON с диска.

## Как устроена страница главы

```text
← Powrót do rozdziałów

ROZDZIAŁ I

🔊 ▶ Posłuchaj

[оригинальный текст]
   трудное слово — нажатие — перевод — закрыть

────────────────
🧠 Sprawdź, czy rozumiesz
[вопросы]
```

Перевод открывается у слова и закрывается крестиком, повторным нажатием, щелчком мимо или клавишей Escape.

## Как добавить новую lekturę

1. Создайте папку `data/nazwa-ksiazki/`.
2. Положите туда `book.json` и файлы глав.
3. Добавьте одну запись в `data/lektury.json`:

```json
{
  "id": "nazwa-ksiazki",
  "dir": "data/nazwa-ksiazki"
}
```

`id` — постоянное имя книги в ссылках. Его лучше не менять после того, как ссылкой уже пользуются.

Обложка — необязательный файл. Путь в `book.json` считается от корня проекта, например `images/nazwa-ksiazki/cover.jpg`.

## Как добавить главу

1. Создайте `data/nazwa-ksiazki/chapter-03.json`.
2. Допишите её в массив `chapters` файла `book.json`:

```json
{
  "id": 3,
  "title": "Rozdział III",
  "file": "chapter-03.json"
}
```

Номер `01`, `02` на странице книги — это порядок в массиве `chapters`. `id` нужен для адреса главы.

## Текст главы

```json
{
  "id": 1,
  "title": "Rozdział I",
  "audio": "",
  "fragments": [
    {
      "text": "Абзац оригинала. Пустая строка внутри text начинает новый абзац.",
      "vocabulary": [
        {
          "phrase": "wdrapać się",
          "match": "wdrapał się",
          "uk": "вилізти, видертися",
          "ru": "взобраться"
        }
      ]
    }
  ],
  "quiz": []
}
```

- `phrase` — что показать в окне перевода (часто инфинитив).
- `match` — как слово стоит в тексте. Если формы совпадают, `match` можно не писать.
- Интерактивными становятся только слова из `vocabulary`. Остальной текст обычный.
- Короткое выражение пишется так же: `"phrase": "na baczność"`.
- Поле `"demo": true` показывает пометку, что текст пробный. У настоящего текста этого поля быть не должно.

Аудио подключается позже. Пока `audio` пустой, кнопка **Posłuchaj** на месте. Когда файл будет готов, укажите путь от корня проекта:

```json
"audio": "audio/chlopcy-z-placu-broni/chapter-01.mp3"
```

Вопросы можно положить и после отдельного абзаца: у фрагмента свой массив `quiz` с той же схемой. Если его нет, вопросы только в конце главы.

## Вопросы

Каждый пункт — одно очко. Типы:

```json
{ "type": "choice", "question": "Kto to jest?", "options": ["Boka", "Nemeczek"], "answer": 1 }
```

```json
{ "type": "truefalse", "question": "Zdanie.", "answer": true }
```

```json
{ "type": "match", "question": "Połącz.", "pairs": [{ "left": "twierdza", "right": "miejsce do obrony" }] }
```

```json
{ "type": "fill", "question": "Nemeczek ___ się na szczyt.", "answer": ["wdrapał", "wdrapal"] }
```

В `fill` строка `___` — место для ответа. В `answer` первый вариант показывается как правильный, остальные тоже засчитываются.

## Quiz

После **Sprawdź** на странице появляется результат, например `4 / 4`. Он живёт только в этой открытой странице. Обновление страницы начинает quiz заново. Результат никуда не записывается.

## Какой файл за что отвечает

| Файл | Роль |
| --- | --- |
| `index.html` | Главная: приветствие и карточки книг |
| `pages/lektura.html` | Страница книги и список глав |
| `pages/reader.html` | Чтение одной главы |
| `js/app.js` | Главная и страница книги |
| `js/reader.js` | Страница главы: текст, аудио, вопросы, переход |
| `js/vocabulary.js` | Подсветка слов и окно перевода |
| `js/audio.js` | Кнопка **Posłuchaj** |
| `js/quiz.js` | Вопросы: выбор, prawda/fałsz, połącz, uzupełnij. Результат только на текущей странице |
| `js/common.js` | Загрузка JSON и адреса страниц |
| `data/lektury.json` | Реестр книг |
| `data/.../book.json` | Название, автор, список глав |
| `data/.../chapter-01.json` | Текст, словарь, аудио, вопросы |
| `css/style.css` | Общий вид, главная, список глав |
| `css/reader.css` | Чтение, словарь, аудио |
| `css/quiz.css` | Вопросы |
| `css/responsive.css` | Телефон и планшет |
